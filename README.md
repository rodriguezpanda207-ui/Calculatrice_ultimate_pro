# 🧮 Calculatrice Ultimate Pro

Une calculatrice de bureau moderne, complète et polyvalente développée en Python avec **Tkinter**. Conçue pour offrir une interface fluide et un mode d'évaluation sécurisé (sans l'utilisation du dangereux `eval()`), elle s'adresse aussi bien aux étudiants qu'aux professionnels et passionnés de programmation.

---

## ✨ Fonctionnalités

* **Multi-modes intelligents** : Simple, Scientifique, Programmeur et Convertisseur d'unités.
* **Gestion des angles** : Modes **DEG**, **RAD** et **GRAD** pour les fonctions trigonométriques.
* **Mémoire complète** : Fonctions `MC`, `MR`, `M+`, `M-`, `MS`.
* **Historique interactif** : Suivi des calculs précédents avec possibilité de double-cliquer pour les réutiliser.
* **Bibliothèque mathématique étendue** :
  * Fonctions trigonométriques et hyperboliques (directes et inverses).
  * Logarithmes et exponentielles (`log`, `ln`, `exp`, `10ˣ`, `eˣ`).
  * Puissances, racines (`sqrt`, `cbrt`), factorielles, combinaisons (`nCr`) et arrangements (`nPr`).
  * Constantes mathématiques intégrées (`π`, `e`).
* **Mode Programmeur** : Conversions entre bases (**DEC**, **BIN**, **OCT**, **HEX**) et opérateurs logiques bit à bit (`AND`, `OR`, `XOR`, `NOT`, `<<`, `>>`).
* **Convertisseur d'unités** : Longueur, masse, température, temps, vitesse, aire et volume.
* **Confort visuel** : Thème Clair / Sombre basculable à la volée.
* **Sécurité** : Évaluateur d'expressions personnalisé basé sur le module `ast` pour une sécurité optimale.

---

## 🛠️ Prérequis

Assure-toi d'avoir installé sur ta machine :
* **Python 3.x** (recommandé : Python 3.12 ou version ultérieure).
* Les modules natifs de Python suffisent amplement (`tkinter`, `math`, `ast`, `re`, `operator`), aucune installation de bibliothèque externe (`pip`) n'est nécessaire.
